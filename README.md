# ViaTradeBackend

Серверная инвестиционная платформа для автоматизированного анализа финансовых инструментов, формирования торговых сигналов и доставки уведомлений пользователям.

Проект разработан в рамках дипломной работы по специальности **09.02.07 «Информационные системы и программирование»**.

## Назначение системы

Платформа предназначена для автоматизации процесса анализа рыночных данных и формирования инвестиционных сигналов на основе заранее настроенных торговых стратегий.

Система позволяет:

* хранить пользовательские данные;
* управлять инвестиционными стратегиями;
* назначать стратегии на финансовые инструменты;
* получать результаты аналитической обработки;
* формировать сигналы на вход в позицию;
* вести статистику эффективности стратегий;
* отправлять уведомления через Telegram.


## Архитектура решения

Проект состоит из нескольких независимых компонентов.
- ViaTradeBackend (этот репозиторий)
- PythonAnalyzer (https://github.com/mrRiten/ViaTradeAnalyzer)
- PythonTgBot (https://github.com/mrRiten/ViaTradeTgBot)

### Основной Backend

Основное приложение реализовано на ASP.NET Core 9 и отвечает за:

* авторизацию пользователей;
* управление сессиями;
* хранение данных;
* работу со стратегиями;
* управление подписками;
* обработку сигналов;
* взаимодействие с внешними сервисами.

### Аналитический модуль

Отдельный Python-сервис выполняет:

* загрузку рыночных данных;
* расчёт аналитических показателей;
* обработку финансовых инструментов;
* подготовку статистики;
* экспорт результатов в CSV.

Обмен данными между аналитическим модулем и Backend осуществляется через файловое взаимодействие.

### Telegram Bot

Отдельный сервис уведомлений принимает запросы от Backend и выполняет отправку сообщений пользователям через Telegram Bot API.

Для взаимодействия используются защищённые системные маршруты и сервисные ключи доступа.

## Запуск проекта

### Требования

* .NET 9 SDK
* MySQLServer
* Python 3.11+
* Git
* Redis

### Backend

```bash
git clone https://github.com/ViaCode-Team/ViaTradeBackend.git
dotnet restore
dotnet ef database update
dotnet run
```

### Analyzer

```bash
git clone https://github.com/mrRiten/ViaTradeAnalyzer
uv sync
python main.py
```
*Анализатор автоматичеки создаст нужные файлы и дериктории для хранения данных парсинга и анализа*

### Telegram Bot

```bash
git clone https://github.com/mrRiten/ViaTradeTgBot
uv sync
python main.py
```
*В конфигурации бота необходимо прописать токен авторизации сервиса, совпадающий с токеном оснвного бэкенда*

## Результат проекта

В рамках проекта была реализована серверная инвестиционная платформа, объединяющая возможности хранения данных, аналитической обработки рыночной информации и автоматической доставки торговых сигналов пользователям.

Архитектура решения позволяет независимо развивать аналитические сервисы, масштабировать серверную часть и подключать дополнительные каналы уведомлений без изменения основных бизнес-процессов системы.
